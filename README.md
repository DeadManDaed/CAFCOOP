# 🍃 CAFCOOP - Application Mobile Agricole

## 📱 Simulation d'Application Android pour Coopérative Agricole Camerounaise

### 🎯 À propos du projet

Cette simulation d'application mobile a été développée pour **CAFCOOP LTD**, une entreprise camerounaise spécialisée dans l'import et la distribution d'intrants agricoles depuis plus de 20 ans.

L'application propose une plateforme complète pour :
- 👨‍🌾 **Les agriculteurs** : Diagnostic phytosanitaire, achat d'intrants, formations
- 👔 **Le personnel CAFCOOP** : Gestion des diagnostics, commandes, stock

## 🧬 Base de Connaissances Pathologies

### 🍫 Cacao (3 pathologies)
1. **Pourriture brune** (Phytophthora) - Gravité: Élevée
2. **Mirides/Capsides** - Gravité: Élevée
3. **Swollen Shoot** (Virus) - Gravité: Très élevée

### 🌽 Maïs (2 pathologies)
1. **Chenille Légionnaire d'Automne (FAW)** - Gravité: Très élevée
2. **Helminthosporiose** - Gravité: Moyenne

### 🍌 Banane/Plantain (2 pathologies)
1. **Cercosporiose noire (Sigatoka)** - Gravité: Élevée
2. **Charançon du bananier** - Gravité: Moyenne

### ☕ Café (2 pathologies)
1. **Rouille du caféier** - Gravité: Élevée
2. **Scolyte des grains** - Gravité: Élevée

### 🌴 Palmier à huile (1 pathologie)
1. **Fusariose** - Gravité: Très élevée

### 🥔 Manioc (1 pathologie)
1. **Mosaïque du manioc (CMD)** - Gravité: Très élevée

### 🍅 Tomate (1 pathologie)
1. **Mildiou** - Gravité: Très élevée

Chaque pathologie inclut :
- Symptômes détaillés
- Causes
- Traitements recommandés
- Mesures préventives

## 🚀 Installation et Utilisation

### Prérequis
- Navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Aucune installation serveur requise

### Lancement
1. **Télécharger** les 3 fichiers dans un même dossier
2. **Ouvrir** `cafcoop_app_enrichie.html` dans un navigateur
3. **Tester** l'application :
   - Vue Agriculteur par défaut
   - Cliquer sur le badge "AGRICULTEUR" pour basculer en vue Personnel

### Mode Démo
- Bouton "🔄 Changer Vue" en haut à droite
- Bascule entre vue Agriculteur et Personnel
- Données de démonstration pré-chargées

## 💡 Cas d'Usage

### Scénario 1 : Diagnostic de maladie
1. Agriculteur observe des taches sur ses cabosses de cacao
2. Ouvre l'app → onglet "Diagnostic"
3. Sélectionne "Cacao"
4. Coche les symptômes observés
5. Prend une photo de la cabosse
6. Envoie le diagnostic
7. Reçoit recommandation : NORDOX 75 WG

### Scénario 2 : Achat d'intrants
1. Agriculteur va dans "Boutique"
2. Parcourt les produits
3. Clique sur "HARVEST MORE 30-10-10"
4. Lit la fiche technique
5. Ajoute au panier (2 kg)
6. Procède au paiement Mobile Money
7. Reçoit confirmation de commande

### Scénario 3 : Gestion par le personnel
1. Personnel CAFCOOP se connecte
2. Consulte les nouveaux diagnostics
3. Examine photos et symptômes
4. Transfère le dossier à un expert agronome
5. Valide les commandes en attente
6. Consulte les statistiques de vente
